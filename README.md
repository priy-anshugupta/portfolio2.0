# Priyanshu Gupta — Cinematic AI Portfolio

Premium cinematic portfolio for an AI Engineer, built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, GSAP, and Lenis smooth scrolling.

## Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — UI animations & variants
- **GSAP + ScrollTrigger** — Laptop opening, timeline, parallax
- **Lenis** — Smooth scroll

## Features

- Cinematic page load sequence
- Hero with mouse-reactive glow & animated roles
- Fake-3D laptop opening About section (CSS perspective + GSAP)
- Animated skills, projects, timeline, achievements
- Magnetic CTA buttons
- Glassmorphism design system
- Fully responsive

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/data/portfolio.ts` for:

- Contact links (email, GitHub, LinkedIn)
- Projects, skills, timeline, achievements
- Hero copy

## Build

```bash
npm run build
npm start
```
